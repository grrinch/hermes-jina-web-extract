# Changelog

## 0.1.0 - 2026-09-24

- Added standalone Jina Reader extraction provider for Hermes `web_extract`.
- Added keyless Reader support and optional `JINA_API_KEY`.
- Added SOCKS5 and HTTP upstream proxy configuration.
- Added JSON transport, 20-second default timeout, browser engine selection, CSS selector waiting, configurable user-agents, selector controls, generated image alt text, and Jina cache headers.
- Added unit tests for provider normalization, configuration, headers, errors, and capability registration.
